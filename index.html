How I Port

📋 Extract VMF, Textures, and Models from BSP

  • Step 1: Download the BSP file of the map you want to port.
  • Step 2: Download BSPSource
  • Step 3: Add your [MAP].bsp file to BSPSource.
  • Step 4: In the "Other" tab, enable "Extract embedded files".
  • Step 5: Click "Decompile".

📋 Edit the VMF in Hammer

  • Step 1: Download Counter-Strike: Source, Team Fortress 2, or Garry's Mod.
  • Step 2: Open the VMF file with Hammer Editor, located at
    C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Source\bin
  • Step 3: Replace any non-rendering textures (like Trigger, NoDraw, PlayerClip, SkyBox) with visible textures.
    -- VMFImport will not generate Parts for these materials --
  • Step 4: If your map has many parts, consider splitting it into stages, segments, or chunks.

📋 Convert Textures to PNG

  • Step 1: Download VTFEdit
    External Tool:
    Crafty Tool on GameBanana – A viewer and converter for Source Engine assets.
  • Step 2: Use the "Convert Folder" option.
  • Step 3: Set the input to the materials folder you extracted from the VMF. Set the output to your working directory for these textures.

📋 Convert Models from MDL to SMD

  • Step 1: Download Crowbar
  • Step 2: Set the input folder to where your extracted MDL files are located, and set the output folder for the decompiled models.

    Click "Decompile".

📋 Convert Models from SMD to OBJ

  • Step 1: Download Blender
    Blender 3D Software:
    Download Blender for Free – Open source 3D modeling and animation tool.
  • Step 2: Download the Blender Source Tools add-on
    Blender Source Tools:
    View on steamcommunity.com – Tools to import/export Source Engine models in Blender.
  • Step 3: Install the Blender add-on.
  • Step 4: Import the SMD file, separate by material, then export the selection as OBJ at 0.1 scale.

Tip: Common stud increments are 0.1, 0.2, 0.4, 0.8, 1.6, 3.2

📋 Import to Roblox

  1. VMF Import

    • Step 1: Download Roblox Studio
    • Step 2: Add the VMF Importer [Beta] plugin

      VMF Importer [Beta] – View on Roblox Plugin Store
    • Step 3: Bulk import your images.
    • Step 4: Save the VMF with only one area active in VisGroups.
    • Step 5: Use the Import VMF [BETA] tool.
    • Step 6: After importing, replace Unions with Parts for accurate collisions.
      Select all triggers by searching in Studio Explorer for "tag:hazardstrip001a" (or whatever material you used for triggers), then group them together.
  2. OBJ Import

    • Step 1: Import the OBJ file. Group meshes and name them after any errored meshes that were imported.
    • Step 2: Attach SurfaceAppearance to models with materials. Use the .mtl files to find the correct textures.
    • Step 3: Use this script to place the Primary Part at the world center for your imported model.
      Replace "workspace["props_not_ready"]["Missing: cyberwave/arch_01"]" with your imported model.

      local model=workspace["props_not_ready"]["Missing: cyberwave/arch_01"] --[[ Model Goes Here --]] local PrimPart=Instance.new("Part") PrimPart.Parent=model PrimPart.Transparency=1 PrimPart.CanCollide=false PrimPart.Anchored=true PrimPart.Name="PrimaryPart" PrimPart.Position=Vector3.new(0,0,0) PrimPart.Size=Vector3.new(3.2,3.2,3.2) model.PrimaryPart=PrimPart

    • Step 4: If the model needs collision, duplicate the Primary Part. Delete duplicate meshes, group it as "Collisions", then move and resize it to fit the model.
    • Step 5: Place entities in a folder named "work" at "workspace.work". Replace "workspace["props_ready"]" with the location of your ready props to replace error meshes.

      local workDir=workspace.work local propDir=workspace["props_ready"] for i, v in ipairs(workDir:GetDescendants()) do if v:IsA'MeshPart' and v.Name=='error' then crntMesh=v.MissingGui.MissingLbl.Text print(crntMesh) if propDir:FindFirstChild(crntMesh,true)~=nil and propDir:FindFirstChild(crntMesh,true):IsA("Model") then print(crntMesh) crntProp=propDir:FindFirstChild(crntMesh,true) crntClone=crntProp:Clone() crntClone:PivotTo(v.CFrame) crntClone.Parent=v.Parent v:Destroy() end end end
